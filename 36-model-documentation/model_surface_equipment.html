5.7. Surface Equipment

5.7.1. Description

The surface-equipment models describe the above-ground assets of a geothermal doublet: separators, filters, heat exchangers, pumps, and gas-fired heat/power units. All models are static models (gemini_model.model_abstract.StaticModel): outputs are computed directly from the current inputs, with no internal state.

Each model exposes a common output pattern where relevant – power_el (electrical power, W), power_th (thermal power, W), and emission (CO2 emissions, kg/s) – so surface-equipment outputs can be aggregated consistently across a project diagram, alongside the equipment-specific pressure/temperature outputs.

5.7.2. Separator

gemini_model.separator.separator.Separator estimates the pressure and temperature drop across a surface separator vessel, using a linear flow-dependent pressure resistance and a fixed temperature drop.

5.7.2.1. Parameters

Parameter

Description

flow_resistance

Linear pressure-resistance coefficient \(R_1\) (Pa/(m³/s))

temperature_drop

Fixed temperature drop across the vessel \(\Delta T\) (K)

5.7.2.2. Inputs

Input

Description

pressure

Known inlet (or outlet) pressure \(P_{in}\) (Pa)

temperature

Known inlet (or outlet) temperature \(T_{in}\) (K)

flow_rate

Volumetric flow rate through the vessel \(Q\) (m³/s)

direction

"forward"/"backward": whether the inlet or outlet state is the known input

5.7.2.3. Outputs

Output

Description

pressure

Computed outlet (or inlet) pressure \(P_{out}\) (Pa)

temperature

Computed outlet (or inlet) temperature \(T_{out}\) (K)

5.7.2.4. Equations

\[P_{out} = P_{in} - Q \cdot R_1 \qquad T_{out} = T_{in} - \Delta T\]

5.7.3. Filter

gemini_model.filter.filter.Filter behaves like the Separator, but its flow resistance increases with flow rate to approximate fouling/clogging of the filter element.

5.7.3.1. Parameters

Parameter

Description

base_resistance

Baseline flow resistance at zero flow \(R_0\) (Pa/(m³/s))

fouling_coeff_a

Fouling resistance asymptote \(a\) (Pa/(m³/s))

fouling_coeff_b

Fouling growth rate coefficient \(b\) (s/m³)

temperature_drop

Fixed temperature drop across the filter \(\Delta T\) (K)

5.7.3.2. Inputs

Same as the Separator model above: pressure, temperature, flow_rate, direction.

5.7.3.3. Outputs

Same as the Separator model above: pressure, temperature.

5.7.3.4. Correlations

\[R_1 = a \left(1 - e^{-bQ}\right) + R_0 \qquad P_{out} = P_{in} - Q \cdot R_1\]

5.7.4. Heat Exchanger

gemini_model.heat_exchanger.heat_exchanger.HeatExchanger models a plate heat exchanger: a linear pressure drop on the primary side, and outlet temperatures on both sides computed with the NTU-effectiveness method for a parallel- or counter-flow configuration.

5.7.4.1. Parameters

Parameter

Description

flow_resistance

Primary-side pressure-drop coefficient (Pa/(m³/s))

heat_transfer_coefficient

Overall heat-transfer conductance \(UA\) (W/K)

flow_configuration

"parallel" or "counter" flow arrangement

fluid_density, specific_heat

(optional) fluid properties \(\rho\), \(c_p\), default to water at STP

5.7.4.2. Inputs

Input

Description

pressure_in

Primary-side inlet pressure \(P_{in}\) (Pa)

primary_temperature_in

Primary-side inlet temperature \(T_{p,in}\) (K)

secondary_temperature_in

Secondary-side inlet temperature \(T_{s,in}\) (K)

primary_flow_rate

Primary-side volumetric flow rate \(\dot{V}_p\) (m³/s)

secondary_flow_rate

Secondary-side volumetric flow rate \(\dot{V}_s\) (m³/s)

secondary_valve_position

Fraction (0-1) of secondary flow routed through the exchanger

5.7.4.3. Outputs

Output

Description

pressure_out

Primary-side outlet pressure (Pa)

primary_temperature_out

Primary-side outlet temperature \(T_{p,out}\) (K)

secondary_temperature_out

Secondary-side outlet temperature \(T_{s,out}\) (K)

heat_duty / power_th

Heat transferred between the two sides (W)

5.7.4.4. Equations

Primary-side pressure drop:

\[P_{out} = P_{in} - \dot{V}_p \cdot R_1\]

Heat capacity rates on the primary and (valve-throttled) secondary side:

\[C_p = \dot{V}_p \rho c_p \qquad C_s = v \cdot \dot{V}_s \rho c_p \qquad C_{min} = \min(C_p, C_s) \qquad C_{max} = \max(C_p, C_s)\]

Number of transfer units, capacity ratio, and maximum possible heat duty:

\[NTU = \frac{UA}{C_{min}} \qquad C_r = \frac{C_{min}}{C_{max}} \qquad \dot{Q}_{max} = C_{min} \left|T_{s,in} - T_{p,in}\right|\]

Outlet temperatures and heat duty, once the effectiveness \(\varepsilon\) is known (see Correlations below):

\[\dot{Q} = \varepsilon \, \dot{Q}_{max} \qquad T_{p,out} = T_{p,in} - \frac{\dot{Q}}{C_p} \qquad T_{s,out} = T_{s,in} + \frac{\dot{Q}}{C_s}\]

5.7.4.5. Correlations

Effectiveness-NTU correlations (Kays & London), selected by flow_configuration.

Parallel-flow:

\[\varepsilon = \frac{1 - e^{-NTU(1+C_r)}}{1+C_r}\]

Counter-flow:

\[\begin{split}\varepsilon = \begin{cases} \dfrac{NTU}{1+NTU} & C_r = 1 \\[6pt] 1 - e^{-NTU} & C_r < 0.01 \\[6pt] \dfrac{1 - e^{-NTU(1+C_r)}}{1 - C_r e^{-NTU(1+C_r)}} & \text{otherwise} \end{cases}\end{split}\]

Parameter

5.7.6.2. Inputs

Input

Description

Inlet pressure \(P_{in}\) (Pa)

pressure_out

5.7.6.4. Equations

5.7.7. Boiler

gemini_model.boiler.boiler.Boiler computes the heat output and CO2 emissions of a gas-fired boiler burning a mixture of gas co-produced with the doublet’s flow and gas supplied from the grid. The fraction \(u\) of available gas the boiler burns is set by burner_modulation; the remainder can supply a co-located CHP unit (see below).

5.7.7.1. Parameters

Parameter

Description

gas_water_ratio

Co-produced gas-to-water volume ratio \(r_{gw}\) (-)

efficiency_factor

Boiler thermal efficiency \(\eta\) (-)

caloric_value

Higher heating value of the gas \(HHV\) (J/Nm³)

gas_emission_factor

CO2 emission factor of the gas (kg CO2/GJ)

gas_density, fluid_density, specific_heat

(optional) fluid/gas properties \(\rho_{gas}\), \(\rho\), \(c_p\)

5.7.7.2. Inputs

Input

Description

temperature_in

Inlet fluid temperature \(T_{in}\) (K)

primary_flow_rate

Primary volumetric flow rate \(Q_p\) (m³/s)

secondary_flow_rate

Secondary volumetric flow rate \(Q_s\) (m³/s)

burner_modulation

Fraction (0-1) of available gas burned \(u\)

secondary_valve_position

Fraction (0-1) of secondary flow routed through the boiler

grid_gas_flow_rate

Supplementary grid gas flow rate \(Q_{grid}\) (m³/s)

5.7.7.3. Outputs

Output

Description

power_th

Heat output of the boiler \(P_{th}\) (W)

5.7.7.4. Equations

\[\dot{Q}_{gas} = \left(r_{gw} \cdot Q_p + Q_{grid}\right) \cdot \rho_{gas} \qquad P_{th} = \eta \cdot HHV \cdot u \cdot \dot{Q}_{gas}\]

5.7.8. Combined Heat and Power (CHP)

gemini_model.chp.chp.CHP shares the Boiler’s fuel/flow accounting, but burns the complementary gas fraction (\(1-u\)) and secondary flow fraction (\(1-v\)), splitting the resulting fuel power into a fixed 1/3 electrical and 2/3 thermal share. Parameters and inputs mirror the Boiler model above; a Boiler and a CHP unit are typically operated together on the same gas and secondary-flow streams, using complementary burner_modulation/secondary_valve_position fractions.

5.7.8.1. Outputs

Output

Description

power_el

Electrical power generated, 1/3 of fuel power \(P_{el}\) (W)

power_th

Heat output, 2/3 of fuel power \(P_{th}\) (W)

5.7.8.2. Equations

\[P_{fuel} = \eta \cdot HHV \cdot (1-u) \cdot \dot{Q}_{gas} \qquad P_{el} = \tfrac{1}{3} P_{fuel} \qquad P_{th} = \tfrac{2}{3} P_{fuel}\]

5.7.9.3. Outputs

5.7.10. Heat Pump

gemini_model.heatpump.heatpump_basic.HeatpumpBasic computes the coefficient of performance (COP), outlet temperatures, thermal production, and electrical consumption of a heat pump, using either a Carnot-efficiency or a Lorenz-efficiency model. It solves the thermodynamic efficiency equation together with the sink/source energy balance, and re-solves with the source outlet temperature clamped at its allowed minimum if the unconstrained solution would drop below it.

5.7.10.1. Parameters

Parameter

Description

mode

"carnot" or "lorenz" efficiency model

eta_carnot

Carnot efficiency factor \(\eta_{carnot}\), 0-1 (-)

eta_lorenz

Lorenz efficiency factor \(\eta_{lorenz}\), 0-1 (-)

COP_0

Initial guess for COP used by the solver (-)

Cp_h, Cp_s

Specific heat of the sink (hot) and source fluids (J/(kg.K))

rho_h, rho_s

Density of the sink (hot) and source fluids (kg/m³)

Th_out_target

Target sink (hot) side outlet temperature (°C)

Ts_in_minimum

Minimum allowed source side outlet temperature (°C)

5.7.10.2. Inputs

Input

Description

Th_in

Sink (hot) side inlet temperature \(T_{h,in}\) (°C)

Ts_in

Source side inlet temperature \(T_{s,in}\) (°C)

qh

Sink (hot) side volumetric flow rate \(\dot{V}_h\) (m³/h)

qs

Source side volumetric flow rate \(\dot{V}_s\) (m³/h)

5.7.10.3. Outputs

Output

Description

COP

Coefficient of performance (-)

Th_out

Sink (hot) side outlet temperature \(T_{h,out}\) (°C)

Ts_out

Source side outlet temperature \(T_{s,out}\) (°C)

Thermal_production

Heat delivered on the sink side \(\dot{Q}_h\) (W)

electrical_consumption

Electrical power drawn by the compressor \(P_{el}\) (W)

5.7.10.4. Equations

Sink- and source-side heat duties, from the energy balance:

\[\dot{Q}_h = C_{p,h} \left(T_{h,out} - T_{h,in}\right) \dot{m}_h \qquad \dot{Q}_s = C_{p,s} \left(T_{s,in} - T_{s,out}\right) \dot{m}_s\]

The COP couples the efficiency equation (see Correlations below) with the energy balance across the compressor:

\[COP = \frac{\dot{Q}_h}{\dot{Q}_h - \dot{Q}_s} \qquad P_{el} = \frac{\dot{Q}_h}{COP}\]

The model solves for \((COP, T_{s,out})\) at the target \(T_{h,out}\) by minimizing the residual of both equations simultaneously. If the resulting \(T_{s,out}\) falls below Ts_in_minimum, it is instead solved for \((COP, T_{h,out})\) with \(T_{s,out}\) fixed at Ts_in_minimum.

5.7.10.5. Correlations

Carnot-efficiency COP, using the sink and source temperatures directly as constant condenser/evaporator temperatures (Carnot, 1824):

\[COP = \eta_{carnot} \cdot \frac{T_{h,out}}{T_{h,out} - T_{s,in}}\]

Lorenz-efficiency COP, using the logarithmic mean temperatures of the sink and source glide, which extends the Carnot cycle to non-isothermal heat exchange (Lorenz, 1894):

\[COP = \eta_{lorenz} \cdot \frac{\bar{T}_h}{\bar{T}_h - \bar{T}_s} \qquad \bar{T}_h = \frac{T_{h,in} - T_{h,out}}{\ln\left(T_{h,in}/T_{h,out}\right)} \qquad \bar{T}_s = \frac{T_{s,in} - T_{s,out}}{\ln\left(T_{s,in}/T_{s,out}\right)}\]
