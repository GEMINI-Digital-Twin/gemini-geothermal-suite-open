5.6. Erosion: Erosional Velocity/Rate

5.6.1. Description

The gemini_model.erosion.erosion_model module is a dispatcher that computes either an erosional rate (mm/year, for a metal-loss correlation) or an erosional velocity limit (m/s, for the API velocity-based approach), depending on the selected erosion_model parameter. Rate-based correlations (DNVGL, OKA, E/CRC Tulsa) return an erosion rate in mm/year, representing expected wall loss due to solid-particle or sand erosion. The API correlation instead returns a maximum recommended flow velocity (m/s) below which erosion risk is considered acceptable.

erosion_model

Correlation

DNVGL

DNV GL RP-O501 erosion rate correlation

OKA

Oka erosion rate correlation

E/CRC Tulsa

University of Tulsa E/CRC erosion rate correlation

API

API RP 14E erosional velocity limit

Use normalize_model_name(name) to resolve a user-facing spelling (e.g. "DNV", "ECRC") to its canonical form, and is_velocity_model(name) to check whether a model produces a velocity limit (API) rather than an erosion rate.

5.6.3. API RP 14E (velocity limit)

gemini_model.erosion.correlation.API.ErosionAPI computes the maximum recommended flow velocity to limit erosion, using the classic API RP 14E “C-factor” approach.

5.6.3.1. Parameters

This model has no configuration parameters.

5.6.3.2. Inputs

Input

Description

rho_fluid

Mixture density of the fluid \(\rho_f\) (kg/m³)

5.6.3.3. Outputs

Output

Description

erosion_velocity_ms

Maximum erosion-limited flow velocity \(U_{erosion}\) (m/s)

5.6.3.4. Correlations

\[U_{erosion} = C_{unit} \cdot \frac{C}{\sqrt{\rho_f}} \qquad C = 125,\quad C_{unit} = \frac{0.3048}{\sqrt{0.0283/0.454}}\]

5.6.6. E/CRC Tulsa

gemini_model.erosion.correlation.TULSA.ErosionTULSA uses a Vickers-to- Brinell hardness conversion and a particle-shape factor.

5.6.6.1. Parameters

Parameter

Description

rho_pipe

Pipe material density \(\rho_{pipe}\) (kg/m³)

5.6.6.2. Inputs

Input

Description

alpha

Particle impact angle \(\alpha\) (deg)

Hv

Particle Vickers hardness \(H_v\) (GPa)

fs

Particle shape factor \(F_s\), 0.2 (rounded) - 1 (sharp) (-)

flowRate, rho_fluid, diameter

Shared flow terms, see “Common flow terms” above

5.6.6.3. Outputs

Output

Description

erosion_rate_mm_yr

Erosion rate \(EL\) (mm/yr)

5.6.6.4. Correlations

Impact-angle function (with \(\alpha\) in radians):

\[F(\alpha) = 5.4\alpha - 10.11\alpha^2 + 10.93\alpha^3 - 6.33\alpha^4 + 1.42\alpha^5\]

Vickers-to-Brinell hardness conversion:

\[H_{v}' = \frac{H_v}{0.009807} \qquad H_{b}' = 0.95057\,H_v' - 0.03743\]

Erosion ratio and rate:

\[ER = C\,H_b'^{\,-0.59}\,F_s\,U_p^{\,n}\,F(\alpha) \qquad C = 2.17\times10^{-7},\ n = 2.41 \qquad \text{[kg/kg]}\]
\[A_t = \frac{A}{\sin\alpha} \qquad EL = (3600\cdot 24\cdot 365.25)\,\frac{ER\,\dot{m}_p}{\rho_{pipe}\,A_t} \quad \text{[mm/yr]}\]

Reference: University of Tulsa Erosion/Corrosion Research Center (E/CRC). http://www.ecrc.utulsa.edu/
