5.4. Reservoir Performance Models

5.4.1. Description

The gemini_model.reservoir package groups models used to characterize reservoir performance from production/injection data: inflow performance, injectivity/productivity indices, reservoir pressure estimation, and bottomhole pressure-drop with skin.

These models underpin the Production well performance and Injectivity Application applications.

5.4.2. Inflow Performance Relationship (IPR)

gemini_model.reservoir.inflow_performance.IPR computes bottomhole pressure for production or injection cases using a linear productivity/injectivity relation.

5.4.2.1. Parameters

Parameter

Description

type

"production_reservoir" or "injection_reservoir"

reservoir_pressure

Reservoir pressure \(P_{res}\) (Pa)

productivity_index

Productivity index \(PI\) (m³/s/Pa), used when type = "production_reservoir"

injectivity_index

Injectivity index \(II\) (m³/s/Pa), used when type = "injection_reservoir"

5.4.2.2. Inputs

Input

Description

flow

Flow rate \(Q\) (m³/s)

5.4.2.3. Outputs

Output

Description

bottomhole_pressure

Bottomhole pressure \(P_{bh}\) (Pa)

5.4.2.4. Correlations

\[P_{bh} = P_{res} - \frac{Q}{PI} \quad \text{(production)} \qquad P_{bh} = P_{res} + \frac{Q}{II} \quad \text{(injection)}\]

Reference: Tarek Ahmed, Reservoir Engineering Handbook (5th ed.), Chapter 7 - Oil Well Performance.

5.4.3. Injectivity Index

gemini_model.reservoir.injectivity_index.injectivity_index computes the injectivity index from measured bottomhole pressure and injection flow rate, i.e. the flow rate achievable per unit of pressure differential.

5.4.3.1. Parameters

Parameter

Description

reservoir_pressure

Reservoir pressure \(P_{res}\) (Pa)

5.4.3.2. Inputs

Input

Description

flow

Injection flow rate \(Q\) (m³/s)

bottomhole_pressure

Measured bottomhole pressure \(P_{bh}\) (Pa)

5.4.3.3. Outputs

Output

Description

injectivity_index

Injectivity index \(II\) (m³/s/Pa)

5.4.3.4. Correlations

\[\Delta P = P_{bh} - P_{res} \qquad II = \frac{Q}{\Delta P}\]

Reference: R. Arnold (2021), Analytics-Driven Method for Injectivity Analysis in Tight and Heterogeneous Waterflooded Reservoir, Proceedings joint convention Bandung.

5.4.4. Reservoir Pressure Estimation

gemini_model.reservoir.reservoir_pressure_estimation.reservoir_pressure estimates (static) reservoir pressure using a linear regression on \(p/Q\) vs. \(1/Q\), derived from a series of flow and bottomhole pressure measurements (a “slope plot” or Hall-type analysis).

5.4.4.1. Parameters

This model has no configuration parameters; it operates directly on the input measurement arrays.

5.4.4.2. Inputs

Input

Description

flow

Array of flow rate measurements \(Q_i\) (m³/s)

bottomhole_pressure

Array of bottomhole pressure measurements \(P_{bh,i}\) (Pa)

5.4.4.3. Outputs

Output

Description

reservoir_pressure

Estimated reservoir pressure \(P_{res}\) (Pa)

r_squared

Coefficient of determination \(R^2\) of the linear fit (-)

5.4.4.4. Correlations

\[\frac{P_{bh,i}}{Q_i} = m \cdot \frac{1}{Q_i} + b \qquad P_{res} = m\]

where \(m\) and \(b\) are obtained from a least-squares linear fit across the measurement series \(i\), and the fitted slope \(m\) is taken as the estimated reservoir pressure. Fit quality is reported via the coefficient of determination:

\[R^2 = 1 - \frac{\sum_i \left(\frac{P_{bh,i}}{Q_i} - \widehat{\frac{P_{bh,i}}{Q_i}}\right)^2} {\sum_i \left(\frac{P_{bh,i}}{Q_i} - \overline{\frac{P_{bh}}{Q}}\right)^2}\]

Reference: Akin (2019), Geothermal re-injection performance evaluation using surveillance analysis methods, Renewable Energy.

5.4.5. Bottomhole and Reservoir Pressure Drop (with Skin)

gemini_model.reservoir.reservoir_pressuredrop.bottomhole_skin_dp computes the pressure components due to radial (Darcy) flow, near-wellbore skin, and the hydrostatic fluid column, for given reservoir rock/fluid parameters.

5.4.5.1. Parameters

Parameter

Description

reservoir_pressure

Reservoir pressure \(P_{res}\) (Pa)

reservoir_radius

Reservoir (drainage) radius \(r_e\) (m)

reservoir_permeability

Reservoir permeability \(k\) (m²)

reservoir_thickness

Reservoir thickness \(h\) (m)

reservoir_top

Depth to top of reservoir, for the hydrostatic column \(z_{top}\) (m)

5.4.5.2. Inputs

Input

Description

flow

Flow rate \(Q\) (m³/s)

viscosity

Fluid viscosity \(\mu\) (Pa.s)

density

Fluid density \(\rho\) (kg/m³)

well_radius

Wellbore radius \(r_w\) (m)

skin_factor

Near-wellbore skin factor \(S\) (-)

5.4.5.3. Outputs

Output

Description

Hydrostatic_dp

Hydrostatic pressure drop \(\Delta P_{HH}\) (Pa)

skin_dp

Skin pressure drop \(\Delta P_{skin}\) (Pa)

bottomhole_dp

Radial (Darcy) flow pressure drop \(\Delta P_{flow}\) (Pa)

reservoir_dp

Total reservoir pressure \(\Delta P_{res}\) (Pa)

5.4.5.4. Correlations

\[\Delta P_{flow} = \frac{Q\,\mu\,\ln(r_e/r_w)}{2\pi\,k\,h} \qquad \Delta P_{skin} = \frac{Q\,\mu\,S}{2\pi\,k\,h} \qquad \Delta P_{HH} = z_{top}\,\rho\,g\]
\[\Delta P_{res} = P_{res} + \Delta P_{flow} + \Delta P_{skin}\]

Reference: Akin (2019), Geothermal re-injection performance evaluation using surveillance analysis methods, Renewable Energy.
