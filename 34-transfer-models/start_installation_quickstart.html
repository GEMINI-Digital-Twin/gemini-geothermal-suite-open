2.1. Quick Start (Beginners)

This page gives you the shortest path to get GEMINI Digital Twin running locally. If you want to understand what each supporting service does, configure a custom plant, or run tests/linting, see the full GEMINI Suite Setup and Local Development Setup guides instead.

2.1.1. What you need

  • Docker Desktop installed and running (https://docs.docker.com/desktop/)

  • Python 3.11

  • Git (https://git-scm.com/downloads)

2.1.2. Steps

  1. Clone the repository:

git clone https://github.com/GEMINI-Digital-Twin/gemini-geothermal-suite-open.git
cd gemini-geothermal-suite-open

  1. Create your environment file from the template:

cp .env.template .env

Open .env in a text editor and fill in at least these values:

GEMINI_PLANT=geothermal_example
GEMINI_FRONTEND_PORT=5101
GEMINI_MYSQLDB_URL=localhost
MONGODB_HOST=localhost
INFLUXDB_URL=http://localhost:8086
CELERY_BROKER_URL=redis://localhost:6379/0
CHROMADB_HOST=localhost
OLLAMA_HOST=localhost
GEMINI_ADMIN_EMAIL=admin@example.com
GEMINI_ADMIN_NAME=admin
GEMINI_ADMIN_PASSWORD=change-me
GRAFANA_URL=http://localhost:3000

  1. Start the supporting services (Grafana, MySQL, InfluxDB, Redis, MongoDB, ChromaDB, Ollama):

docker compose up -d

  1. Install Python dependencies and run the app:

pip install poetry
poetry install
poetry run python src/gemini_interface/app.py

  1. Open the app in your browser:

http://localhost:5101

Log in with the GEMINI_ADMIN_EMAIL / GEMINI_ADMIN_PASSWORD you set in step 2.
