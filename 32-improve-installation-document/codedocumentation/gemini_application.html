5.3. gemini_application

GEMINI Application: End-user applications built on the GEMINI Digital Twin.

Provides user-facing workflows and modules that integrate models and the framework into runnable applications.

Modules

application_abstract

Abstract base class for end-user applications with plant and unit management.

chatpopup

Chat-based popup application (LLM, embeddings, vector store).

esp

ESP application.

injectionwell

Injection well application.

productionwell

Production well application.

reportgenerator

Report generation application.

tagbrowser

Tag browser generation application.

wims

Well Integrity Monitoring System (WIMS) application.
