Welcome to the GEMINI Technical User Manual

Note

GEMINI is under active development (MVP3 and later). Screens and features may evolve between releases.

This manual is written for technical users of the GEMINI geothermal digital twin, including operators, engineers, and project administrators. It provides:

  • platform background and architecture (Section 1)

  • first-time usage guidance (Section 2)

  • project configuration instructions (Section 3)

  • detailed application manuals (Section 4)

  • key definitions in the glossary (Section 6)
