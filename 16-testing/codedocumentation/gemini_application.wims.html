5.3.8. gemini_application.wims

Well Integrity Monitoring System (WIMS) application.

Modules

common

Shared helpers for WIMS application workflows.

corrosion_from_logs

Utilities for processing caliper logs and deriving measured corrosion outputs.

corrosion_from_prod_data

Utilities for corrosion rate estimation from production data.

corrosion_model

CO2 corrosion analysis application with caliper log processing and model optimization.

erosion_from_prod_data

Erosion rate estimation from production / injection flow data.

erosion_from_tally

Build erosion flow-path segments from well tally and ESP geometry.

erosion_model

Erosion analysis application for WIMS.

model_optimization

Per-joint CO2 corrosion parameter calibration using SciPy minimize.
