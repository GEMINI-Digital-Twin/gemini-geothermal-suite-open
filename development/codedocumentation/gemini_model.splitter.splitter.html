6.1.17.1. gemini_model.splitter.splitter

Splitter model.

Splits a single input into an arbitrary number of numbered outputs by fixed fractions, e.g. secondary flow routed to both a Boiler and a CHP, or a single production header feeding several parallel branches. Generalizes the fixed 2-output splitter used in earlier doublet models to N outputs.
