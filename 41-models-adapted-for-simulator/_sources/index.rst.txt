Welcome to the GEMINI Technical User Manual
===========================================

.. note::

   GEMINI is under active development (MVP3 and later). Screens and features may
   evolve between releases.

This manual is written for technical users of the GEMINI geothermal digital twin,
including operators, engineers, and project administrators. It provides:

* platform background and architecture (:numref:`about-gemini`)
* first-time usage guidance (:numref:`getting-started`)
* project configuration instructions (:numref:`system-setup`)
* detailed application manuals (:numref:`applications-section`)
* key definitions in the glossary (:numref:`gemini-glossary`)
