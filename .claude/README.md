# .claude: what agents read (gemini)

`.claude/` holds what agents and Claude Code sessions read about this repo; `docs/` holds what
people read. Read both, and the project-wide context in the project root (`../.claude/AGENTS.md`,
`../.claude/` with the shared memory, `../documents/`). Layout and naming rules:
`../.claude/README.md`.

| Folder | Holds |
|---|---|
| `docs/` | Reference for the code, listed in `AGENTS.md`. |
| `notes/` | Current work on this repo: the GEMINI II and GEMINI III handovers. |
| `archive/` | Finished work: task prompts (`prompts/`), phase prompts (`phases/`), old notes (`notes/`). Read only when the history of a decision matters. |
