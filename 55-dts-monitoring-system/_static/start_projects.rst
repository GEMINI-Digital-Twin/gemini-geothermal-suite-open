.. _projects:

Projects
===========================
Projects represent the digital twin configuration for a plant or asset.

**Permissions overview**

* Regular users can create and edit projects assigned to them.
* Administrators can assign users and delete projects.

Create New Project
---------------------------

1. Sign in with your account.
2. Open the **File** menu and select ``New Project``.

    .. image:: images/Start_project_0.jpg
        :width: 100%

3. Enter the project name and confirm.

    .. image:: images/Start_project_1.jpg
        :width: 100%

        
4. Confirm the success message.

    .. image:: images/Start_project_2.jpg
        :width: 100%


Assign users to a project (administrator)
-----------------------------------------

1. Sign in with administrator credentials.
2. Open ``Admin Manager`` from the top-right user menu.

    .. image:: images/Start_project_3.jpg
        :width: 100%

3. In the **Project** tab, select the project and assign users or groups. Click
   **Save**.
 
    .. image:: images/Start_project_5.jpg
        :width: 100%
    
4. Use the **User** tab to review registered users and group memberships.

    .. image:: images/Start_project_6.jpg
        :width: 100%



Open Existing Project
---------------------------

1. Sign in with your credentials.
2. Open **File** -> ``Open Project``.

    .. image:: images/Start_project_8.jpg
        :width: 100%

3. Select a project assigned to your account and click **Open**.

    .. image:: images/Start_project_9.jpg
        :width: 100%
        
4. Wait for the project load confirmation.

    .. image:: images/Start_project_10.jpg
        :width: 100%
        
5. You will be redirected to the project's main page.

    .. image:: images/Start_project_11.jpg
        :width: 100%

Delete Project
---------------------------

Only administrators can delete projects.

Administrator steps:

1. Sign in as administrator.
2. Open the target project and select **File** -> ``Delete Project``.

    .. image:: images/Start_project_12.jpg
        :width: 100%

3. Confirm deletion.

    .. image:: images/Start_project_13.jpg
        :width: 100%

4. Close the project after deletion.

    .. image:: images/Start_project_14.jpg
        :width: 100%
    
5. Open **Admin Manager** and remove the project entry from the **Project** tab
   (trash icon or ``Delete`` from the dropdown).

    .. image:: images/Start_project_15.jpg
        :width: 100%
        
6. Confirm deletion.

    .. image:: images/Start_project_16.jpg
        :width: 100%

7. Verify the success message.

    .. image:: images/Start_project_17.jpg
        :width: 100%
