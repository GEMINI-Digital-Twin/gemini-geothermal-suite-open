# GeoDesign agent memory

Persistent lessons learned across sessions. Append short, dated, factual notes with `edit_file`.

- (2026-11-05, session 20261105-152650-fb88, verifier rejection) When the user specifies a design, simulate and present exactly that design (every stated capacity, depth and temperature).
- (2026-11-05, session 20261105-152650-fb88, verifier rejection) Write each number with the unit of its fact field (e.g. EUR/MWh, t CO2/yr, MW).
- (2026-11-05, session 20261105-153710-2e45, verifier rejection) Every number must come from a tool result or the brief; never quote a number that is not in a recorded fact.
